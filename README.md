\# SoftUni JavaScript Solutions



Това хранилище съдържа моите решения на задачи и лабораторни упражнения от обучението ми в \*\*СофтУни\*\*. Проектите тук служат като архив на моя напредък, практическа подготовка и развитие като софтуерен инженер.



\## 📂 Структура на хранилището



\* \*\*JS Fundamentals\*\* — Фундаментални знания за езика: променливи, условни конструкции, цикли, масиви, функции, работа с обекти и асоциативни масиви, както и базови алгоритмични задачи.

\* \*\*JS Advanced\*\* — Дълбоко навлизане в езика: манипулация на DOM дървото (DOM Manipulation) и работа със събития (Events), усъвършенствани функции, детайлно изучаване на обекти, класове и прототипи (Prototypes), концепции за обектно-ориентирано програмиране (ООП) в JS, както и unit testing.



\## 🛠️ Използвани технологии \& Среда

\* \*\*Език:\*\* JavaScript (ES6+)

\* \*\*Среда:\*\* Node.js

\* \*\*Редактор:\*\* VS Code
